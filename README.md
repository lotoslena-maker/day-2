# AI Agents Ukraine 🇺🇦

A simple educational web page about **AI agents**, designed in a modern Ukrainian visual style.

The project explains what AI agents are, how they work, which components they use, and includes a small interactive simulator that demonstrates a simplified agent workflow.

## Features

- Warm neutral design with red accents and a Ukrainian-inspired ornament
- Accessible navigation, keyboard focus styles, and reduced-motion support
- Responsive layout for desktop, tablet, and mobile
- Sections explaining:
  - AI agent capabilities
  - Agent workflow
  - Agent architecture
- Interactive **AI Agent Simulator** with example tasks (local educational simulation, no AI service connection)
- Built with plain HTML, CSS, and JavaScript

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
